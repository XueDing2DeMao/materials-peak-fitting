# 合成示例

以下数据由数学函数生成，不包含个人实验数据，不对应真实样品或化学态。完整操作见[使用手册](../docs/USER_GUIDE.md)。

| 文件 | X / Y 列 | 生成参数 |
| --- | --- | --- |
| `single_peak_demo.csv` | `x` / `intensity` | X=0～10，步长 0.05；面积归一化 Gaussian，A=100、xc=5、FWHM=1.2；背景 10+0.2x |
| `xps_doublet_demo.csv` | `binding_energy_eV` / `intensity` | E=280～292 eV，步长 0.05；两个 PsdVoigt1，(A,xc)=(120,284)、(60,287)，共用 w=1.2、mu=0.35；背景 20+0.2(E−280) |

单峰扰动为 `0.08 sin(7x) + 0.04 cos(13x)`；XPS 扰动为 `0.10 sin(5(E−280))`。这些确定性扰动用于观察非零残差，不模拟特定仪器的噪声分布。峰面积参数为全域积分面积，不能用有限区间数值积分要求严格相等。

两个 CSV 均使用 UTF-8、逗号分隔和首行列名。
