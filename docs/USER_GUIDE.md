### 界面与键盘操作

顶部“输入方式”选择“原始谱线拟合”或“拟合结果解析”；已有峰参数表可直接进入后者，操作见[末节](#拟合结果解析与材料参数计算)。原谱工作区右上角分别选择“分析类型”和“处理方式”。分析类型分为通用谱线、XRD 峰拟合和 XPS 峰拟合；处理方式分为单谱拟合和批量拟合。峰数由手动添加的峰决定。切换分析类型不会转换数据或单位，各类型的单谱配置和批量草稿分别保留在当前页面会话中。

| 分析类型 | 适用场景 | X 轴要求 |
| --- | --- | --- |
| 通用谱线 | Raman 等一维谱线的单峰或多峰分析 | 使用原文件单位；界面显示 X/Y |
| XRD 峰拟合 | 一个或多个衍射峰的峰位、宽度和面积 | 2θ，单位为 ° |
| XPS 峰拟合 | 同一能区的多分量与双峰约束 | 结合能，单位为 eV |

三种分析类型均可使用批量拟合。批量策略可选“独立拟合”（各谱从同一模板开始）或“顺序拟合”（继承上一条有效结果）。读取、预检或运行批次时导航暂时锁定；暂停须等当前谱求解返回后才可切换。

单谱与批量图表均关闭滚轮缩放，滚轮用于滚动页面。需要调整图表视图时，使用工具栏的“框选缩放”“放大”“缩小”，或通过“重置坐标轴”恢复视图；这些视图操作不修改分析区间或拟合结果。

![紧凑工作台：顶部模式、数据来源与常驻图谱](images/43-workbench-redesign.png)

**界面总览。** 新版采用浅色科研工作台与深蓝主操作，截图展示公开 XPS 数据。下文部分功能示例保留上一版配色，入口位置以本节为准。科研图表中的连线仅连接已有采样点。

- **顶部数据栏**：核对文件、工作表、X/Y 列与有效点数；在“查看全部数据 / 更改列”弹窗中修改后点击“应用到图表”。数据清理审计收在“数据详情与清理记录”中。
- **左侧拟合设置**：按“分析区间”“基线／背景与复核”“峰与参数”排列；通用／XRD 使用“统一调整峰参数”，XPS 使用逐峰“参数”按钮；求解设置按需展开。
- **右上分析画布**：查看原谱、基线、拟合曲线和残差；“调整范围”与“框选分析区间”修改分析区间。当前编辑模式明确显示，点击“结束编辑 · 返回浏览”或按 Esc 退出。主图与残差的 X 轴同步缩放和平移，XPS 保持结合能倒序。
- **结果面板**：点击“结果与诊断”展开，通常位于图谱右侧，桌面窗口较窄时位于图谱下方。通过“结果概览／完整参数／诊断详情／比较与归档”切换内容，也可独立收起；切换不会清空图谱、配置或临时比较选择，也不会重新拟合。

界面以浅灰蓝背景、白色面板和深蓝操作区分层级，科学曲线保留原有颜色和线型。桌面设置栏内容独立滚动，底部固定显示拟合按钮与阻塞原因。拖动分隔线可调整设置／结果栏宽度，也可在“布局”中使用加减按钮或恢复默认；宽度仅保留在当前页面。点击“放大图谱”集中检查主图与残差，按 Esc 返回。顶部“分析进度 · 保存与恢复”管理手动保存与恢复。

“复用拟合设置”和“用于批量拟合”位于工作区顶部操作栏，后者在当前结果收敛且未过期时可用。曲线／参数／图片／配置通过“比较与归档”页签中的“导出”菜单保存；“方案敏感性比较”和“分析摘要”也位于该页签。诊断建议可定位背景、峰设置或具体参数，调整后重新拟合。背景预览仍须人工勾选复核；修改设置后的过期结果会禁用导出。

## 安装与启动

### 环境准备

Windows 启动脚本要求 Python 3.10～3.12，以及 Node.js 18 或更高版本（含 npm）。Python 推荐使用 3.11 或 3.12；依赖中的 NumPy 要求 `>=1.26,<2`，不要直接用 Python 3.13/3.14 创建环境。后端依赖范围见 `backend/requirements.txt`，前端锁定版本见 `frontend/package-lock.json`。

可在 PowerShell 检查：

```powershell
python --version
node --version
npm.cmd --version
```

下载项目后先解压到可写目录。以下命令均从项目根目录执行，不要求固定磁盘或用户名。

### Windows 一键启动

双击 `一键启动.bat`。脚本先检查 5175、5176 端口，然后创建或复用项目 `.venv`、安装后端依赖；缺少前端依赖时使用 `npm ci` 安装。首次安装需要联网。

启动后打开 <http://127.0.0.1:5175/>。保留启动窗口，结束时按回车；脚本只停止本次启动的服务。日志在 `.logs/`。也可以运行 `一键启动.bat -NoBrowser` 或 `一键启动.bat -Check`；后者在前后端返回 HTTP 200 后退出，不进行数值正确性验证。

### 手动安装与双终端启动

确认 `python --version` 在上述范围内，再安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
cd frontend
npm.cmd ci
cd ..
```

第一个 PowerShell 窗口，在根目录启动后端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 5176
```

第二个 PowerShell 窗口，从根目录进入前端并启动：

```powershell
cd frontend
npm.cmd run dev -- --host 127.0.0.1
```

访问 <http://127.0.0.1:5175/>。手动启动时分别在两个窗口按 Ctrl+C 停止。开发前端固定请求本机 5176 后端，因此不要只改后端端口后期待页面自动适配。

### 构建后单服务运行

完成依赖安装后，可先构建前端，再启动后端：

```powershell
cd frontend
npm.cmd run build
cd ..
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 5176
```

此时访问 <http://127.0.0.1:5176/>。后端在启动时检测 `frontend/dist` 并挂载静态页面；必须先构建、后启动。该方式仍面向本机，不是公网服务部署方案。

## 首次拟合教程

本教程采用 Gnatyuk 等公开的锗材料谱数据，数据集 DOI 为 [10.5281/zenodo.18845748](https://doi.org/10.5281/zenodo.18845748)，许可为 CC BY 4.0。原文件、完整署名、关联出版物、校验和与处理说明见[公开数据说明](../examples/public/README.md)。三份工作簿已随仓库提供，下载整个项目即可复现。

### 第一步：选对工作表和谱列

1. 点击“导入实验数据”，打开 [Raman.xlsx](../examples/public/zenodo_18845748/Raman.xlsx)。
2. 导入后自动打开核对弹窗，先浏览工作表全部数据（每页 100 行，支持跳页），再选择工作表 **Bare Ge**、X 列 **Wavenumber**、Y 列 **Pristine #1**，点击“应用到图表”。
3. 检查顶部文件名和列名。表格共 1601 行，数值清理后用于显示的有效配对点为 1600；两者不是同一统计口径。

![公开 Raman 原谱的工作表与谱列选择](images/17-data-selection.jpg)

**图 1｜导入与谱列核对。** 截图展示待应用的 Bare Ge 原谱和原始行预览，点击“应用到图表”之前不会加载建议列或清除旧分析。默认工作表 `Figure2bc` 存放峰位和峰宽统计，**不是待拟合原谱**。不要直接对默认选择开始拟合。

### 第二步：设置区间和基线

在“1 分析区间”中将下限设为 **280**、上限设为 **320**，输入后检查主图上方的区间数值已同步。选择“直线”，本例不添加手动锚点，使用区间两端的自动估计；点击“预览基线”，检查后勾选“已复核当前基线”。

**明确分析区间。** 输入的是 280～320 cm⁻¹，真正参与拟合的是其中的 52 个采样点，实际端点约为 280.734 和 319.882 cm⁻¹。主图仍可显示完整光谱，改变拟合区间并不等于自动缩放视图。

### 第三步：选择峰形并拟合

在“统一峰函数”选择 **PsdVoigt1**，点击“添加峰”，再点击“自动估计并采用初值”，保持默认分阶段求解，点击“开始拟合”。本例没有手动固定参数或额外边界。

![Raman 的 PsdVoigt1 模型选择与拟合结果](images/18-single-results.jpg)

**图 3｜模型、状态和导出入口。** 左侧选择峰形并编辑初值，右上查看谱线和残差，右下读取收敛状态、峰性质并导出。Raman 界面当前使用通用 X/Y 单位标识；本数据的 X 单位由原表确定为 cm⁻¹。

### 第四步：对照结果和残差

下面将同一次复算的拟合区间单独放大。上图保留所有区间内观测点，下图为观测值减总拟合；曲线连接模型在原采样点处的计算值，没有补造观测点。

![公开 Raman 数据的局部拟合与残差](images/raman-public-fit.png)

**图 4｜局部峰形与残差。** 单条 `Pristine #1` 光谱，n=52 个谱点，不是 52 次独立实验。直线背景固定，PsdVoigt1 参数自由优化；未对原谱平滑、归一化或平均。没有绘制重复测量误差条。

| 复算项目 | 本例结果（约值） | 含义 |
| --- | --- | --- |
| 峰顶 xc | 301.11090 cm⁻¹ | 本模型的实际峰顶 |
| 整体 FWHM | 4.22921 cm⁻¹ | 当前背景和峰形下的半高全宽 |
| 全域面积 A | 115277.39 | 原始强度单位 × cm⁻¹；含区间外外推 |

## 导入自己的数据

### 文件准备

支持 CSV、TXT、TSV、DAT、XY、XYE、XLS、XLSX、XLSM，单文件不超过 25 MiB。文本优先使用 UTF-8；读取器也尝试 GB18030，并自动推断分隔符。简单格式如下：

```csv
x,intensity
100,15.2
101,17.1
102,23.4
```

这三行只展示格式；单峰拟合区间至少需要四个有效点，实际谱线应有足够密集的采样。读取器支持无表头数值文本，以及以 `#`、`;`、`//` 开头的注释行。仪器二进制文件不能通过改后缀获得支持，应先在仪器软件中导出文本或表格。

Excel 可以选择工作表；表头应放在首行。导入后在弹窗浏览全部工作表与数据列，区分原谱、统计值和误差列。建议 X/Y 仅是草稿，必须点击“应用到图表”；之后可在“查看全部数据 / 更改列”重新选择。应用将所选列转换为数值，排除非有限值和无效配对行，然后按 X 升序排序。检查显示的点数和谱形是否符合预期。

更改列时，选择区是待应用草稿，顶部摘要和曲线仍表示当前数据；点击“取消”可恢复已应用选择。点击“应用到图表”并读取成功后，如存在已编辑工作会提示替换影响；确认后摘要、曲线、来源及单谱状态一起更新。取消、读取失败和过期请求均不能覆盖当前分析。预览失败会保留原数据并显示错误；更换文件读取失败也会保留原文件，并明确提示当前仍使用的文件名。顶部同时列出有效 XY 点数与工作表总行数，避免混淆。

### 坐标和数据质量

- Raman：X 使用实际波数；XRD：X 使用以度为单位的 2θ；XPS：X 使用结合能 eV。应用不转换单位。
- X 和 Y 必须是不同列。拟合区间内重复 X 会触发错误；请依据采集方式在外部处理重复测量。
- XYE 的第三列不会自动成为测量误差权重；当前工作流使用所选 X/Y。
- 不自动裁剪原始负强度，也不把残差负值归零。

“查看全部数据 / 更改列”弹窗显示全部解析数据，每页 100 行，可上一页、下一页或输入页码跳转。所有解析后的列均可查看，包括文本和未选为 X/Y 的列；X/Y 列用底色和标签标记。表头固定，宽表仅在表格内横向滚动。关闭、取消或 Esc 返回原入口并保留当前谱线；只有“应用到图表”才提交列选择。

解析器会移除全空行／列，浏览表不再执行 X/Y 有效性筛选或排序。解析行号不含表头，不等同于文本文件的物理行号；缺失值显示“—”，非有限值显示 Infinity / -Infinity。会话恢复后的“查看会话原谱”仅显示已保存的 X/Y 快照，其他工作表和列需重新导入原文件。

![完整数据核对弹窗：全部列、分页与显式应用](images/40-data-import-dialog.png)

![手机导入弹窗：固定底部应用与取消操作](images/41-data-import-mobile.png)

上传数据存放在本机后端内存中。用于换列预览的数据登记会在创建约一小时后被后续请求清理；出现“数据已失效”时重新导入。刷新页面或停止服务前，请在顶部“分析进度 · 保存与恢复”下载会话 JSON，并保留原始文件。已保存的原谱快照不依赖服务内存数据集，恢复后如需更改列仍需重新导入原文件。

### 查看数据清理记录

应用数据列后，数据栏下方显示有效配对数、排除行数、是否稳定排序以及重复 X 数。“查看清理与行号记录”列出 X/Y 空值、非数值、无穷值及最多 200 行明细。原因按 X/Y 分别计数，同一行可能对应多项原因，因此原因次数不一定等于排除行数。

解析行号不含表头，也不是原文本的物理行号；汇总基数为既有解析流程移除全空行后的工作表。排序后每个观测点的解析行号映射保存在会话审计中。重复 X 保留，程序不会自动平均、插值或修补。旧服务未返回可选 `audit` 时明确显示“未提供”，不会假定零排除。

## 单峰与 XRD 操作

### 选择模式和区间

右上角“分析类型”提供“通用谱线”“XRD 峰拟合”和“XPS 峰拟合”，选中后会显示用途或 X 轴要求。分析当前一条谱线时选择“单谱拟合”；单谱工作区支持手动添加一个或多个峰。

通用谱线和 XRD 峰拟合共用已应用数据，各自保留单谱配置与结果；XRD 以 2θ（°）标识横轴、峰位和 FWHM，原谱拟合不自动转换数据或作物相鉴定。需要晶面间距、展宽校正与相干域尺寸等二次计算时，使用独立的[材料参数工作区](#拟合结果解析与材料参数计算)，按方法补齐参考和适用条件；原谱中的观测宽度保留不变。

在左侧输入区间起点和终点，或使用“框选分析区间”。点击“调整范围”后，可以拖动两侧边界，也可以通过上方箭头整体平移；点击“完成调整”或按 Esc 收起手柄。点击图中的起点、终点圆点可定位对应输入框。选择区间时保留足够背景，避免把相邻峰误纳入单峰解释。

### 公开 XRD 示例

导入 [XRD.xlsx](../examples/public/zenodo_18845748/XRD.xlsx)，选择 **BareGe → 2Theta → Pristine Ge**，点击“应用到图表”，再选择“XRD 峰拟合”。注意这里的 `BareGe` **没有空格**。将区间设为 **65.8～66.6°**，使用无手动锚点的默认直线背景，预览并复核基线，选择 PsdVoigt1，手动添加一个峰，采用自动初值后拟合。

![公开 XRD 数据的局部拟合与采样点](images/xrd-public-fit.png)

**图 5｜XRD 单峰操作与采样限制。** 一条原谱的局部区间，n=31 个谱点；未做平滑、归一化或仪器展宽校正。复算峰顶约 **66.20816°**、FWHM 约 **0.05184°**、R² 约 **0.997326**。原谱步长约 0.02626°，一个 FWHM 只有约两个采样间隔，峰宽对模型和采样较敏感；不要把小数位数等同于测量精度，也不要直接用此宽度推断晶粒尺寸。线段连接模型采样值，尖锐外观不表示新增了实验点。

完整设置和输出见 [xrd-result.json](../examples/public/results/xrd-result.json)。

### 设定基线

基线先由锚点确定，拟合过程中固定；峰参数优化不会同时重新估计基线。

| 类型 | 输入要求 | 当前实现 |
| --- | --- | --- |
| 无基线 | 无锚点 | 基线恒为零，适合已完成背景校正的数据 |
| 常数 | 至少一个有效锚点 | 使用锚点 Y 的平均值 |
| 直线 | 至少两个不同 X 的锚点 | 连接最左和最右锚点；额外内部锚点不改变直线 |
| 多项式 | d 阶需要至少 d+1 个不同 X 的锚点，d 为 1～8 | 对锚点拟合多项式 |
| Spline | 至少三个不同 X 的锚点 | 三次插值样条；锚点覆盖范围外保持端点值 |
| B-Spline | 至少四个不同 X 的锚点，平滑强度非负 | 平滑样条；覆盖范围外保持端点值 |

侧栏中“生成建议锚点”与“编辑基线锚点”并列，可直接生成建议点；点击“编辑基线锚点”打开坐标弹窗，集中添加、修改或删除锚点。图中编号与弹窗中的行号对应。弹窗修改即时生效，“完成”“关闭”或 Esc 保留修改，“撤销本次修改”恢复本次打开前的锚点。

也可直接单击图中锚点，打开弹窗并定位到该锚点的 X 输入框。点击“图上编辑锚点”后，拖动编号圆点调整 X、Y，松开后生效；拖动中按 Esc 取消。拖动限制在当前可见绘图区和分析区间内；编辑结束可点击“结束锚点编辑”返回浏览。修改锚点后，旧基线预览和复核状态会失效，需要重新预览并复核。

将锚点放在有依据的背景位置，核对图中编号和输入坐标；重复 X 不计为独立约束，后端会拒绝重复锚点。使用建议锚点后同样需要预览并勾选“已复核当前基线”。“预览基线”用于检查当前配置计算的基线，并不证明背景选择正确。

未提供手动锚点时，界面允许的默认直线流程可使用区间端点估计。端点若仍有明显峰尾，应调整区间或手动指定锚点。提高多项式阶数不保证更可靠，过于灵活的基线可能吸收真实峰信号。

### 初值、约束与求解

选择峰模型后，可用“自动估计并采用初值”估计参数。自动分析只提供候选和起点，不是最终拟合，也不自动确认峰的物理来源。

侧栏显示参数摘要；点击“统一调整峰参数”，在弹窗中查看完整数值并填写初值、下限、上限。摘要仅缩短显示，不改变实际参数精度。上下限留空时使用模型边界；“固定”表示该参数不参与优化。初值必须位于允许范围内，宽度必须满足模型要求。

全部峰表将标签、启用、参数初值、上下限和固定开关并列显示；窄屏可在表格内横向滚动，内容较多时在弹窗内纵向滚动，底部操作保持可见。XPS 参数按峰打开。修改即时生效，“完成”“关闭”或 Esc 均保留修改；关闭后返回设置，点击“开始拟合”才会执行求解。

![390 像素窄屏下的峰参数编辑和撤销入口](images/20-parameter-undo-mobile.jpg)

弹窗中的数值是求解起点，拟合完成后不会自动替换为最优参数。最终数值请到“拟合结果”中读取。初值估计会更新当前峰形的初值，但不会清除已设置的上下限或固定开关；重新估计后应核对两者是否兼容。

展开“求解设置”，默认勾选“固定峰中心预拟合，再释放中心”。展开“求解参数”可查看中心固定阶段上限（20 次函数评估）、最大函数评估次数（2000）和收敛阈值（`1e-8`）。求值次数并非实验重复次数；遇到失败，先检查数据、基线、峰形和约束，再决定是否增加上限。

改变区间、基线或参数后，旧结果可保留用于对照，但会标记“已过期”并禁用导出；重新拟合后才能导出当前结果。

## 峰形与参数口径

统一术语：`A` 为**模型全域积分面积**，`xc` 为**实际峰顶位置**，FWHM 为**半高全宽**，HWHM 为**半高半宽**，`mu`（μ）为 Lorentzian 混合比例。面积单位为 Y 单位乘 X 单位，净峰高使用 Y 单位，宽度和峰位使用 X 单位。

| 模型 | 主要参数 | 宽度解释 |
| --- | --- | --- |
| Gaussian | A、xc、w | w 是整体 FWHM |
| Lorentz | A、xc、w | w 是整体 FWHM |
| PsdVoigt1 | A、xc、w、mu | Gaussian 和 Lorentz 分量共用 w，w 是整体 FWHM |
| PsdVoigt2 | A、xc、wG、wL、mu | wG、wL 是两个分量各自的 FWHM；整体 FWHM 另行计算 |
| Split Pseudo-Voigt | A、xc、h_low、h_high、mu | 两侧 HWHM 不同，整体 FWHM = h_low + h_high |
| EMG（高 X / 低 X 拖尾） | A、xc、sigma、tau | sigma 是高斯核标准差，tau 是指数尾尺度，两者均不等于整体 FWHM |

EMG 在 `tau=0` 时退化为 Gaussian。拖尾方向按 X 数值增减定义，XPS 倒序横轴不改变这个定义。本项目的 Split Pseudo-Voigt 归一化和 EMG 峰顶重定位有具体实现，不能直接套用其他软件同名模型的参数。

“连续模型峰性质”从连续函数计算整体 FWHM、两侧半宽、净峰高、全域面积、当前区间模型面积和区间覆盖比例。区间积分使用实际参与拟合的数据端点与解析原函数/CDF；全域面积包含区间之外的模型外推。半高交点超出数据范围时会提示，不能将其当作已充分测量的峰宽。

旧字段 `derived_parameters.area_in_range` 使用采样点梯形积分；新字段 `peak_geometry.area_in_range` 使用模型积分。两者不能混为同一数值口径。无有效宽度时返回空值和原因；派生峰性质暂不报告标准误或置信区间。

## XPS 多峰操作

### 一次完整分析

1. 导入结合能和强度数据，在“更改列”中选择对应列，再切换到“XPS 峰拟合”。横轴从高能向低能显示。
2. 输入区间下限和上限，或在图中框选。“拖动区间”改变分析范围，“平移视图”只改变可见视图。
3. 选择无背景、直线或静态 Shirley。可手填低/高能端水平，也可留空采用相应端点窗口的中位数。区间变化后按需点击“窗口重置到区间两端”。
4. 点击“预览背景”。使用 Shirley 时，检查后勾选“已复核当前 Shirley 背景”，才能拟合。
5. 点击“添加单峰”，或“检测候选峰”后逐个选择。点击各峰“参数”打开编辑弹窗，调整标签、峰形、初值、上下限和固定参数；“参数含义”可展开查看，并可撤销本次打开以来的修改。候选只提供初值；后续预览不会覆盖人工初值。
6. 有独立依据时设置峰组关系，然后点击“开始拟合”。图中分量为净峰，总拟合只叠加一次背景。
7. 检查各分量、总拟合、残差和参数状态，保存结果与配置。改变设置后重新拟合再导出。

### 峰组和约束

“添加双峰组（同宽）”使用你给出的峰间距与第二峰/第一峰面积比，不预设元素。可创建峰位偏移、面积比例和宽度比例关系：

```text
目标峰.xc = 来源峰.xc + 偏移值
目标峰.A  = 来源峰.A  × 面积比例
目标峰.w  = 来源峰.w  × 宽度比例
```

同类宽度关联支持 `w↔w`、`h_low↔h_low`、`h_high↔h_high`、`sigma↔sigma`；`tau` 可设初值、边界或固定值。被绑定参数通过独立根参数展开，子参数边界会传播到根参数。约束冲突、循环关联或停用被引用的来源峰会阻止有效求解。

删除被关联峰前，先点击“解除该峰的所有关联”；切换峰形遇到不兼容关系时，也应先解除冲突。增加峰数会增加参数，并不自动增加解释可信度。

### 能量校准与 Shirley 的含义

能量偏移采用 `E_corrected = E_raw + shift_eV`，同步平移区间、端点窗口和峰位。填写“校准依据”；应用不会自动判断荷电校正。

静态 Shirley 在能量升序上迭代：

```text
B(E) = B_low + (B_high − B_low) × ∫low^E(y − B)dE / ∫low^high(y − B)dE
```

积分使用真实采样步长。背景计算后固定，不随峰参数优化更新。净积分非正或背景不收敛会报错，不自动回退到其他背景模型。参数误差也不包括背景选择或校准的不确定性。

### 数值与诊断

先判断优化是否收敛，再检查参数是否可辨识，最后结合实验依据判断模型是否适用。这三个问题不能用一个 R² 代替。

单峰、多峰、XPS 和批量使用同一峰结果表，默认展示峰顶位置、整体 FWHM、当前区间模型面积及其占比；全域面积可勾选显示，也可在详情中查看。摘要另列 R²（扣背景信号）和 RMSE。峰顶与整体宽度取自连续模型计算结果，不能用分量宽度代替；旧结果缺少这些字段时显示“—”，需重新拟合。全域面积包含模型在拟合区间外的外推部分，区间面积只覆盖实际拟合端点。

默认收起“峰参数与置信区间”“连续峰性质”“质量与残差指标”“求解过程”和“模型比较”。点击相应标题查看完整内容；求解器原始消息和分阶段记录位于“求解过程”。收敛状态与模型适用性分开提示，峰性质警告、初值及不确定性警告仍直接显示。结果内容随页面滚动，底部集中曲线、参数、图片和配置导出；逐峰详情使用模态弹窗。拟合期间或设置改变后禁用导出，重新拟合完成后恢复。

| --- | --- |
| R²、调整 R² | 描述当前模型对数据变异的解释程度；不能据此确认物理机制 |
| RMSE、SSE/RSS | 残差尺度与残差平方和；比较时保持同一数据和预处理 |
| 残差方差估计 | 无权重的残差平方和/自由度，单位为强度²，不是已按测量误差标准化的 χ² |
| 残差趋势、Durbin–Watson、异常点 | 诊断线索；仍需观察结构性偏离、局部肩峰和背景错误 |
| AICc、BIC | 在可比的数据、区间、背景和权重条件下比较模型；AICc 点数不足时为空 |
| 参数贴边、秩不足、标准误为空 | 查看原因并复核约束或模型；空值不是零误差 |
| 区间覆盖比例不足、半高点超界 | 提示外推对面积/宽度的影响；按实验条件扩大测量或分析范围 |

模型比较默认比较四种对称单峰；勾选“加入非对称模型”后扩展为七种。推荐结果不会自动替换当前选择；需要自行选择模型并重新拟合。

XPS 的 R² 使用扣背景信号。EMG 自由尾尺度很小（`tau/sigma < 1e-3`）时会提示弱尾，不报告不适用的线性标准误；`tau` 固定为零时，可辨识的 Gaussian 宽度仍可估计误差。标准误和置信区间都依赖当前模型、约束和固定背景。

XPS 面积占比使用当前能区内启用分量的积分面积总和作分母，**不是元素原子百分比**。当前不支持 Tougaard、多重态专用模型、自动化学态归属、RSF 定量、测量误差加权和批量联合拟合。

### 采样支持与方案敏感性

结果区展开“采样支持与峰宽解释”，查看半高区间内的**实际观测点数**及相邻正间隔的最小值、中位数、最大值；非均匀采样按实际坐标计算。没有有效半高区间或不足两个局部观测点时，相关间隔显示缺失和原因。半高点超出观测范围会提示模型外推，不设未经验证的统一“合格点数”阈值。

![XRD 半高区实际点数和观测峰宽说明](images/32-sampling-diagnostics.jpg)

公开 XRD 演示中半高区间内实际有 2 个点，间隔约 0.0262606°；这与模型给出的连续 FWHM 是不同信息。观测峰宽未扣除仪器展宽，不能据此直接推断晶粒尺寸。

在工作区底部展开“方案敏感性比较 · 不修改主配置”：

1. 点击“保存当前拟合为主方案”，冻结当前结果及其配置。
2. 修改替代方案的区间、背景或自由参数初值；固定值和绑定约束保持。
3. 预览方案背景并勾选“已检查此方案区间与背景”，再单独计算。
4. 表格比较峰顶、FWHM、区间面积和全域面积，展开诊断查看警告。失败方案保留原因；主工作区变化后明确标记旧配置。

最多保留 8 个替代方案；重新保存主方案会清空旧比较。临时比较不进入本地会话，可用比较面板下方的 HTML 摘要归档。主配置与结果不会被替代方案覆盖。不同背景或观测点集的 AICc/BIC 不自动排名，方案差异不能当作置信区间或完整系统误差。

## 导出与恢复

### 输出内容

| 文件 | 用途 |
| --- | --- |
| 单峰曲线 CSV | `x, raw_y, baseline, net_y, peak_y, total_y, residual` |
| 单峰参数 CSV | 参数、误差、边界、固定状态、拟合设置、统计量及 `geometry.*` 峰性质 |
| XPS 曲线 CSV | 原始/校准能量、原始强度、背景、分量、净峰总和、总拟合、残差 |
| XPS 参数 CSV | 分量参数、约束相关状态、统计量和峰性质 |
| XPS 配置 JSON | 保存当前结果及其源信息、数组与分析配置，供严格匹配后复用设置并重新拟合 |
| PNG | 导出当前拟合谱图，用于展示；不代替数值结果归档 |

建议把原始文件、参数 CSV、曲线 CSV、PNG 和 XPS 配置保存在同一分析目录，并记录样品、采集条件、单位、校准依据、软件提交版本和分析日期。通用／XRD 也支持配置 JSON，单峰配置保留求解设置；配置和 CSV/PNG 都不等于可恢复的完整会话。

### 恢复 XPS 配置

1. 重新导入**原始文件**，选择原工作表和原 X/Y 列。
2. 切换 XPS，点击“复用拟合设置”。支持配置导出文件，也支持含 `configuration` 的 XPS 拟合结果 JSON。
3. 应用严格核对文件 SHA-256、工作表、谱列和原始数组。Excel 即使数值未变，重新保存后文件字节也可能变化，导致校验失败。
4. 载入后复核背景，必要时重新勾选 Shirley 复核，再执行拟合。文件中的旧结果不会被直接当作当前可信结果。

旧峰形和旧参数配置使用版本 1；包含新峰形或新参数时使用版本 2。当前支持版本 1/2，内外版本必须一致。不要手改版本号绕过校验。

切换分析类型保留各自状态，确认应用新谱会重置各类型单谱设置。刷新页面不会自动恢复会话。结果失效时 CSV／PNG／配置导出被禁用。XPS 页面直接导出当前结果快照，曲线、参数和配置对应同一次计算，不重新求解；底层旧导出接口保留，但页面不再调用它。本地会话和 HTML 分析摘要可归档旧结果并保留失效标记，不重新求解。

### 工作保护与撤销

参数修改即时生效；“撤销本次修改”恢复本次打开参数弹窗时的快照，包含标签、启用、峰函数、参数和相关约束。关闭后再次打开会建立新快照。应用另一份数据后旧快照失效，不能跨数据恢复；修改或撤销后应重新拟合。

应用新数据、载入替换配置、更换已有批次模板或清空已有批次结果时，会说明影响并请求确认，默认聚焦“取消，保留当前工作”。取消或 Esc 保留原工作；确认清空批次结果会保留已导入谱线，便于重新预检。

![窄屏工作保护：默认取消，可用 Esc 保留当前结果](images/25-work-protection-mobile.jpg)

有当前工作时，刷新或关闭页面会请求浏览器显示离开提醒；浏览器可能限制提示是否出现及其文字。**这不是自动保存**，确认离开后当前会话仍会丢失。CSV、PNG、配置 JSON 和批次追溯 JSON 均不代表完整会话可恢复；请使用顶部独立的“保存分析进度”下载可恢复会话；没有自动保存。

### 本地会话 JSON（独立版本 1）

顶部“分析进度 · 保存与恢复”提供“保存分析进度”和“恢复分析进度”。先完成或暂停正在进行的操作，再保存**当前选中的单谱或批次**；其他分析页不一并归档。批次必须先纳入所选谱线并完成全部有效预检。未纳入草稿、候选峰状态、方案比较临时编辑与 HTML 用户备注不属于会话。

会话文件保存原始 X/Y 快照、文件哈希及谱列身份、当前配置、各结果对应的配置、失效标记、单峰求解设置、数据审计，以及批次顺序、尝试／父来源、诊断、人工接受和样品条件记录。格式标识为 `spectral-fit-session`、`session_version: 1`，与批次追溯 v2 分开；旧追溯文件不能在此恢复。

载入先完整检查结构、容量、原谱与结果观测的一致性以及继承引用，再说明影响并确认覆盖。错误或不支持的文件不会部分替换当前工作。单谱数据是应用级共享数据，因此载入单谱会重置其他类型的单谱工作区；各类型批次独立。取消覆盖保留原工作。

服务重启后仍可载入查看结果，不需要原有 `dataset_id`。恢复不会自动拟合，旧背景复核不用于新的计算：单谱先重新预览并复核；批次点击“重新预览恢复背景”，逐条或全部复核后显式继续。已完成结果、人工接受和警告保留；中断尝试标为失效，未完成谱线等待新的求解。顺序拟合从最后有效且获准的父结果重建继承，跳过或重跑会断开相应旧链。

缺少原谱快照时先显示只读结果，当前工作区不替换。点击“匹配缺失的原文件”，按 SHA-256、工作表、X/Y 列匹配，再逐点核对观测值；全部补齐后才能确认恢复计算。只读结果也可导出分析摘要。

限制：100 MiB、100 条谱、累计 200,000 个原谱点；另有结构安全上限（400 万节点、深度 32、单行 100 次尝试）。超限拒绝，不截断。无自动保存、数据库或后台续算，请保管下载文件及原始实验文件。

![恢复批次保留中断尝试和上一条结果继承来源](images/34-restored-batch-history-mobile.jpg)

### 可打印 HTML 分析摘要

单谱、批次与方案比较面板均可展开“分析摘要 · 可打印 HTML”，填写用户备注后导出。HTML 直接引用已保存结果，不调用求解器；备注单列为非软件计算结论，文件名、标签与备注均按文本转义。失效结果标记为旧配置。

## 通用多峰与批量顺序拟合

### 单谱线多峰

设置区按“分析区间 → 基线／背景与复核 → 峰与参数”排列。拟合按钮下方会显示当前无法继续的原因；必需复核项以醒目提示呈现。基线说明、求解设置和未使用的峰间约束按需展开；XPS 的能量校准、背景端点与双峰组也集中在折叠区。参数弹窗内修改即时生效，关闭或 Esc 保留修改；结果弹窗只读。峰性质的计算方法与不确定度说明位于“计算口径与不确定度”中，警告仍直接显示。

1. 选择“通用谱线”或“XRD 峰拟合”及“单谱拟合”，导入数据并应用 X/Y 列。默认不创建峰，也不自动检测峰；由用户手动选择峰位和峰数。
2. 与单峰使用同一套分析区间控件：默认平移视图；点击“框选分析区间”水平拖动，按选中数据点确定起终点并自动退出；点击“调整范围”拖动两侧边界，或拖动上方箭头整体平移。Esc 收起手柄，双击主图恢复手柄；点击图上的区间端点可聚焦左侧输入框。XPS 倒序轴上的手柄仍对应数值下限／上限。随后设置基线，点击“预览基线”，检查后勾选“已复核当前基线”。修改区间、数据或基线会撤销确认。
3. 点击图表上方“图上添加峰”，再在当前拟合区间内单击目标位置，即可建立峰位初值。无需点中已有散点；开启后可连续左键添加多个峰，右键点击峰位标记附近删除该峰（空白处不删除；有关联约束时先解除关联），直到点击“取消添加峰”或按 Esc 退出。峰显示同色虚线与峰编号／xc 坐标标注；拟合前标注当前初值，拟合后标注结果 xc，编辑、停用或删除峰会同步更新。Esc 或“取消添加峰”可取消。拖动不添加峰。XPS 同样支持，坐标按校准后的结合能解释。
4. 也可使用左侧“添加峰”或“检测候选峰”。手工添加默认位于最高点，多个峰应分别设置不同峰位。候选峰不能代替对重叠峰数量的判断。
5. 在“统一峰函数”中选择一种峰函数（默认 Gaussian），应用于所有已有峰和后续新增峰。点击“统一调整峰参数”，在同一个弹窗表格中逐峰修改标签、启用状态、面积、峰位、宽度等初值、上下限和固定状态；关闭或 Esc 保留修改，“撤销本次修改”恢复打开时的标签、启用、模型、参数和约束。PsdVoigt2 分别设置 wG/wL。峰间仍可关联峰位差、面积比和同名宽度参数比；若切换函数会移除关联参数，需先解除相应关联。旧混合峰配置可恢复，但需手动统一函数后再拟合。
6. 点击“开始拟合”，检查总拟合、各净峰和残差。通用多峰与 XPS 结果区默认显示收敛状态、峰数、R²（扣背景）、RMSE 和各峰对比表；警告摘要保持可见，展开可查看完整说明及强相关参数。点击峰名称突出曲线，点击独立“详情”按钮打开该峰的详细求解结果弹窗，查看参数、标准误和连续峰性质；弹窗内容独立滚动，按 Esc 或点击“关闭”返回对比表，焦点回到原峰入口；其他指标在“统计与求解详情”中查看。对比表的峰顶位置与整体 FWHM 使用连续模型峰性质，缺失项显示“—”。全部固定参数时显示“固定参数计算”。收敛不等于模型适用。
7. 通过结果标题右侧“导出”菜单导出曲线 CSV、参数 CSV、配置 JSON 或谱图 PNG。通用多峰导出保存完整结果快照，不受详情展开状态或界面显示精度影响；编辑后结果失效，必须重新拟合才能导出。恢复配置需匹配原文件哈希、谱列及实际数据。

### 批量：独立拟合与顺序拟合

1. 在单谱工作区完成首谱拟合，点击“用当前配置批量拟合”，会携带拟合参数并进入对应分析类型的批量页面。一峰配置也可作为模板。也可直接选择“批量拟合”，通过“从单谱建立模板”返回配置，或“加载模板 JSON”读取同类型的配置/拟合结果文件；加载使用文件中保存的 configuration/request 参数，类型不匹配会拒绝加载。
2. 在“导入与配置”中选择或拖入一个或多个文件，也可继续追加文件。读取完成后自动打开“选择 X / Y 数据”弹窗，文件先进入草稿，尚不生成任务。左侧搜索和切换文件，右侧切换工作表；列角色表显示列名及前 3 行示例，X 单选、Y 多选，非数值列禁选，选择某列为 X 时会取消该列的 Y 勾选。Y 默认不勾选；可搜索列、展开完整列名、选择本表其余数值列，或直接使用弹窗顶部常驻的“选择全部候选 Y”与“清空全部 Y”（作用于全部文件，包含搜索隐藏项）。“应用列规则到其他文件…”先预览按列名或原始列位置（包含文本列）的匹配结果，再替换勾选且匹配的工作表选择，未匹配项保留原选择并标记。底栏显示已选文件数与将新增谱线数，点击“纳入所选谱线”才生成任务。关闭或 Esc 暂存草稿，可从页面入口重新打开；“取消本次导入”丢弃本次草稿，保留旧批次及背景复核。支持前 5 行原始值预览；“查看全部数据”在只读弹窗中浏览所有工作表、列及分页数据，不改变批次谱列选择。误差、温度、统计列由用户判断，不会自动被当作权重或实验条件。100 条上限按实际纳入数量计算，候选列可超过 100。相同文件哈希、工作表和 X/Y 的重复选择会提示，不自动删除，也不应当作独立重复实验。部分文件失败保留成功草稿，未处理草稿时不能开始拟合。
3. 确认 X 单位和校准一致。默认对每条谱重新估计端点背景；显式锚点必须选择“固定绝对背景”，且仅在确实具有相同背景时使用。背景不同的实验应先在单谱工作区调整并分批处理。
4. 点击“预检并进入背景复核”。系统提前保存每条 X/Y 快照并检查文件来源、区间覆盖、重复 X、约束传播及点数是否大于自由参数数目。预检完成后收起导入配置，有失败项时优先定位失败谱线。新增背景概览每页 6 条，整批使用相同坐标范围与原始强度，不归一化或平滑；实线是原谱，虚线是预检背景。点击缩略图查看完整谱线，不会自动复核。检查后可逐谱勾选或“复核本谱并查看下一条”；“一键全部复核”覆盖本批次全部预检成功项（包含筛选隐藏项），失败项跳过。开始运行前可撤销本次全部复核，保留原先已勾选项；修改输入或重新预检清除旧复核。无背景自动通过。复核后仍需手动开始拟合；背景复核不代表拟合合格，也不会自动接受拟合警告。
5. 选择批量策略并开始运行。“独立拟合”每条谱均从模板初始化；“顺序拟合”首谱从模板初始化，后续谱使用前一条获准结果的自由参数作为初值。两种方式都保留当前模板固定值和约束，每条单独优化，背景、来源和统计量不从上一条照搬。
6. 评估次数耗尽时续算一次；仍失败时用模板回退一次，每谱最多三次自动尝试。默认连续计算全部曲线，不因拟合警告或单条失败暂停。不可辨识、贴边、强相关、峰序变化或残差一阶相关系数绝对值大于 0.5 的收敛结果保留为“待复核”（沿用现有后端阈值）；失败保留尝试与错误。异常结果不会自动接受或传递初值，下一谱从模板开始。批次结束后可逐条接受结果、标记跳过或调整重跑，警告和历史始终保留；事后接受不会重算已完成的下游谱线。通用的标准误计算前提仅作为说明，不单独触发警告。
7. 暂停／停止在当前后端求解返回后生效。选择已有任务可以调整自由初值并从该谱重跑，后续旧结果会失效，历史尝试仍保留。
8. 第五项“导出结果”可选择当前谱线或整个批次，导出参数 CSV、曲线 CSV 或追溯 JSON；默认范围为当前谱线。导出不重新拟合，均包含相应谱线的历史尝试、失败、跳过及失效标记；JSON 包含每次请求、来源、父任务、尝试号和结果。批次 JSON 已升为版本 2，新增实验记录映射；CSV 列保持原样，不包含新增记录。旧外部读取程序可能需适配版本 2。

导出面板按所选范围显示已完成计算、待复核、失败、待执行、运行中和已跳过的数量。“查看待复核结果”或“查看失败谱线”会返回结果页，清除列表筛选并定位相应谱线。运行中仍可导出截至点击时的记录，不等待剩余计算。文件生成失败时显示原因，重新点击可重试；“已发起下载”表示文件已交给浏览器，保存位置请查看浏览器下载列表。

## 拟合结果解析与材料参数计算

此工作区读取已经完成拟合的峰参数表，也可接收本项目已有结果。它不要求重新导入原谱或重新拟合；文件读取成功只表示表格可解析，计算结果还取决于量义、单位、参考数据和方法条件。

### 导入、映射与复核

1. 顶部选择“输入方式 → 拟合结果解析”，在“导入与映射”中选择 CSV、TXT、TSV、DAT 或 Excel（XLS／XLSX／XLSM），可一次选择多个文件。核对工作表、表头行、数据起止行和表征类型；“浏览完整原始表”可分页查看全部列与原始值。
2. 宽表选“每行一个峰”，分别映射样品、谱、峰、模型和峰位／峰宽／峰高／面积列；长表选“每行一个参数”，映射参数名、数值、单位、标准误及作用层级。长表中的同一峰由样品／谱／峰标识合并，未识别的参数名可补充别名。缺少标识时生成的技术 ID 只便于追踪，不证明真实样品或物理峰相同。
3. 明确峰位是 `2θ`、峰顶还是模型位置，峰宽是 FWHM、HWHM 还是 Gaussian σ，面积是全域还是指定区间积分，并填写源报告的单位。未知定义保留待复核；只有明确 Gaussian σ 或兼容的对称模型 HWHM 才转换为 FWHM，不能将任意模型的“width”直接当作 FWHM。
4. 参数标准误（SE）映射到各参数；RMSE、R²、RSS、χ² 等保留为谱级指标，不能当作每个峰的 SE 或测量权重。长表谱级行可用 `Scope=spectrum`，其峰编号可留空。单位按源报告声明，缺失或非法值留空并记录原因，不填零；导入 SE 不代表已经传播到材料参数的不确定度。
5. 点击“解析当前文件”或“解析并纳入…”后，到“峰参数与异常”核对标准值、定义、单位、原值、文件／工作表／行列来源和警告。坏字段或坏行保留异常，不吞掉其他有效记录；某个无关字段失败时，仍可使用该行足够且明确的其他字段计算。

确认列结构后，可“保存当前映射”，再应用到当前或全部文件，也可导出／载入映射模板。模板保存列角色、定义和单位，不能代替对新文件量义的复核；缺少所需列时保留原映射并提示。物相、温度等文本或数值可补在实验元数据中；积分范围、参考来源和适用条件在对应材料方法表单中填写。

![峰表解析与独立归档恢复（合成演示数据）](images/54-peak-results-desktop.jpg)

### 选择方法并计算

在“材料参数”中选择全部或部分峰，填写方法表单，先点击“检查表达式与配置”，再计算。配置检查通过不代表每条记录都适用；结果表分别保留有效值、表观值或拒算原因，方法版本、完整输入、配置和输入指纹可在回归明细中查看。

| 方法 | 必需条件与输出边界 |
| --- | --- |
| 用户公式 | 变量绑定峰字段、带单位常量或实验元数据；输出填写名称、表达式和单位。支持四则运算、受限幂及白名单数学函数，禁止任意代码；单位或量义不相容、缺值、除零及非有限结果拒算。角度先用 `radians` 转为弧度再做三角运算。 |
| 晶面间距／立方晶格常数 | 明确峰位为 2θ，提供波长，按一阶 Bragg 关系计算 d；已知立方晶系及非零 hkl 时再计算 a。不同峰可逐峰填写 hkl；没有 hkl 只算 d，不推断物相或非立方晶格。 |
| Scherrer 相干衍射域尺寸 | 提供波长、FWHM、K 及其来源。Gaussian 用平方差、Lorentz 用线性差扣除同条件仪器展宽；可填单个宽度或角度—宽度表，表内插值不外推。已有校正宽度须声明来源，不能重复校正；混合峰形不能直接套用纯 Gaussian／Lorentz 扣除。仅在显式选择表观模式时允许未校正估计。结果是相干衍射域尺寸，不能直接称为显微组织晶粒尺寸。 |
| 相对晶面应变 | 用 `(d-d0)/d0`，提供同一 hkl 的无应力参考 d0、来源和相容条件；d 可直接给定或由 2θ 与波长求得。正负值均有意义，输出相对晶面应变及微应变单位值，不代表完整应力张量，也不是 WH 展宽微应变。 |
| 各向同性 WH 模型微应变 | 按样品或谱分组，至少三个同相、不同角度的有效峰，明确 Lorentz 线性展宽及各向同性近似，提供校正来源或 Lorentz 仪器校正。回归 `β cosθ = Kλ/D + 4ε sinθ`；负斜率或非正截距报告无物理有效解并保留诊断，不截为零。β 统一为弧度 FWHM，不能混用不同宽度定义。 |
| 标样线性校准组分含量 | 使用至少三种不同浓度的标样，或有来源且给定有效范围的已有斜率／截距，按 `信号 = 斜率 × 含量 + 截距` 反算。须声明组分、含量口径、信号单位、背景和匹配的测量条件；区间面积还需同一积分范围。FTIR 使用明确吸光度响应，不能把透过率积分直接当作吸光度面积。超标样范围拒绝外推；面积占比不是含量，质量／摩尔／体积分数不能互换，也不代替 XRD RIR 或 XPS RSF 定量。 |

公式可添加多个输出，并在后一步引用已命名输出。例如变量 `p` 绑定峰位，依次定义 `twice = 2*p`、`back = twice/2`，两项输出均填原峰位单位。执行范围可选逐峰、按样品分组或按谱分组；分组绑定可选求和／均值，同组必须具有相容单位和相同数量定义，不能把全域面积和区间面积混算。公式保留适用条件说明；自定义公式的存在不等于通过某个材料方法的科学适用性审核。

### 使用内置结果、保存与导出

无结果或结果已过期时，材料参数入口禁用并显示原因；完成拟合后启用。原谱工作区顶部“用拟合结果计算材料参数”会将当前单谱或批次的已有结果转入解析工作区，沿用模型、连续峰性质、来源及警告，不触发重新拟合。过期、失败或缺失结果仍保留其状态；补齐波长、仪器参考或标样等条件后再计算。

修改映射、峰参数、公式或配置会使旧计算快照失效；历史仍可查看和归档，但不能当作当前设置的结果。有效行继续计算，失败项单独说明；遇到整体配置错误或资源限制时，先修正配置或缩小批次。

“导出与归档”提供标准峰参数 CSV、二次计算结果 CSV、异常记录 CSV 和可打印 HTML 摘要；导出引用已有快照，不重新计算。通过“保存完整档案”下载 `format: peak-analysis`、`schema_version: 1` 的 JSON，保留标准记录、来源、映射模板、方法配置、计算历史和失效标记。用“恢复解析档案”恢复；这与原谱本地会话 `spectral-fit-session` 和批次追溯 JSON 是独立格式，不能混用入口。

档案恢复不重新拟合或计算，也不恢复未纳入的原文件草稿。请同时保存原始文件；需要重新映射时再次导入原文件。页面刷新不会自动保存工作区。

### 合成验收样例与限制

样例位于 [`examples/acceptance/peak_analysis/`](../examples/acceptance/peak_analysis/)：

| 文件 | 用法与检查内容 |
| --- | --- |
| `xrd-single.csv`、`xrd-single.xlsx` | 同一条合成 XRD 峰的宽表，映射 `Center/FWHM/Height/Area` 和 `Center_SE/FWHM_SE`，声明 2θ、FWHM、角度单位 deg、全域面积。使用 λ=0.15406 nm、立方晶系、hkl=(111)，得到 a≈0.2668397474 nm；K=0.9、Gaussian 仪器 FWHM=0.1° 时，D≈52.96192675 nm。系数和仪器参考均为本例指定的合成条件。 |
| `ftir-long.csv` | 合成 FTIR 长表，映射 `Parameter/Value/Unit/SE/Scope`，声明峰顶位置、FWHM、区间面积。面积为 7，谱级 RMSE 独立保存；以含量 0／2／4 mg/mL、响应 1／5／9 的标样和积分范围 1000—1100 cm⁻¹校准，得到 3 mg/mL。须填写合成吸光度响应、背景和一致条件说明。 |
| `mixed-quality.csv` | 含有效峰及非法峰位、负峰宽、缺面积的记录。按 XRD 宽表映射后检查异常定位，再计算 d，确认有效峰可计算、坏峰报告原因。 |

在项目根目录执行以下命令，脚本只读样例并打印核对结果，同时检查多步公式、相对晶面应变以及合成 WH 回归：

```powershell
.\.venv\Scripts\python.exe examples/acceptance/peak_analysis/reproduce.py
```

这些文件验证解析、算术和异常隔离，不是实验测量或厂商认证证据；尤其合成 FTIR 不能替代真实测量验收。真实厂商导出格式尚未固定，需以代表性文件核对列结构、宽度／面积定义、误差口径和来源。

单文件不超过 25 MiB；每批标准化及每次计算最多 10,000 个峰。计算请求另受累计文本 10 MiB、100 万输入节点及预估 200 万公式运算节点限制；公式单条最多 2,048 字符、256 个表达式节点，每次最多 20 个输出。峰数未达上限也可能因复杂记录或多步公式超限，此时按样品／谱分批，并保留完整分组需要的峰。以上为资源保护上限，不是性能承诺。新增材料参数未实现不确定度传播，也未增加 Rietveld 全谱精修、自动物相鉴定、RIR 或 RSF 定量。
