# Design System — 材料谱线拟合工作台

## 1. Product and audience

面向材料科学与工程领域的工程师和研究人员。用途是材料表征谱线分析、单峰/多峰/XPS 拟合、批次分析和结果复核。界面语言为简体中文，科学符号、变量和单位保持规范。

本文件是现有产品的设计上下文，可用于 Stitch 导入设计规则。目标是改进操作效率、信息密度与可读性，不改变计算或研究结论。截图内的数值仅为示例，不能作为新计算结果。

## 2. Visual theme

专业、克制的浅色科研工作台。使用清晰的分区、精细边框和适度留白。让谱图与结果成为主要视觉内容。避免大面积装饰、营销首屏、过大的卡片和占据图表空间的装饰图。

## 4. Typography and spacing

- 中文字体：Microsoft YaHei / PingFang SC / system-ui / sans-serif。
- 当前字号参考：标题 23px、分区 18px、次级标题 16px、正文 14px、辅助信息 12px；保持易读，避免进一步压小辅助文本。
- 数值使用等宽数字，清楚显示单位与有效数字；科研数值不得擅自四舍五入或改成 K/M 简写。
- 间距采用 4、8、12、16、24、32px 的层级。
- 控件圆角约 6px，面板圆角约 10px，面板内边距约 16px。
- 桌面常规控件约 40px 高，主要执行按钮 44px；移动端触控目标至少 44px。

## 5. Layout

- 桌面优先，参考宽度 1440px；兼容 1280px 和 1920px。
- 顶部保留工具名称、分析类型、单谱/批量切换、本地会话入口。
- 数据源摘要展示文件、工作表、X/Y 列、有效点数与数据审计入口。
- 左侧约 332px 为参数设置，内部可滚动；底部主要执行按钮持续可见。
- 右侧依次展示谱图/残差、诊断与结果、比较与归档。
- 批次模式左侧是可搜索和筛选的谱线列表，右侧是当前谱的曲线、诊断、复核与结果。
- 移动端参考宽度 390px；设置与结果按阅读顺序堆叠，宽表仅在局部容器横向滚动，不能撑宽整页。

## 6. Required interaction patterns

### Peak results

紧凑结果表保留峰名称、峰顶位置、整体 FWHM、区间面积、区间面积占比及可选全域面积。峰名称本身是唯一的详情入口，点击打开参数弹窗，同时突出对应曲线。不要额外添加每行“详情”按钮。关闭弹窗后焦点回到峰名称。面积占比不等于原子百分比。

### Data import

导入文件后打开“数据导入与完整预览”弹窗。顶部显示文件信息、工作表、X 列、Y 列；中部展示全部解析列及分页数据，标记所选 X/Y 列。每页 100 行，支持上一页、下一页、页码跳转、总行数和解析行号。保留非数值单元格，不只显示前五行。

表格表头固定，横向/纵向滚动限制在表格区域；底部“取消”和“应用到图表”持续可见。仅应用后更新主图；取消或 Esc 不改变已应用数据。覆盖已有分析结果时保留工作保护流程。移动端字段纵向排列。

“全部数据”指解析器保留的数据，不是原 Excel 的格式、公式或被排除的全空行列。恢复会话只有已保存的 X/Y 快照时明确标记“会话原谱”，不得伪装成原文件的全部列。

### Analysis and review

保留分析区间、背景预览/复核、峰参数与约束、开始拟合、残差、警告与采样诊断。XPS 保留结合能方向、能量校准和峰组约束。计算收敛、诊断状态和人工复核分别呈现；收敛不等于模型适用。

### Batch and archive

保留批次预检、背景复核、逐谱状态、尝试记录、当前谱导出、实验条件与样品信息、趋势查看和手动会话保存/载入。不要用视觉上的批量勾选绕过背景复核。恢复会话后不自动启动拟合。

## 7. Accessibility and states

按钮、输入框、页码与峰名称可键盘操作；提供可见焦点。弹窗具有名称和焦点管理，Esc 可退出允许关闭的状态，关闭后返回入口。区分加载、空数据、错误、重试、禁用与已修改状态。主操作附近说明阻塞原因，错误紧邻相关输入。

`screens/02-import-dialog-desktop.png`、`screens/03-peak-results-desktop.png`、`screens/06-import-dialog-mobile.png` 是最近的交互参考，应优先于其他截图中较旧的数据入口。其他截图用于整体布局、批次模式及响应式参考。不要将不同状态误拼成一张同时显示的页面。

## 9. Implementation handoff

现有工程是 Vue 3 + TypeScript + Vite + Plotly。设计稿应能转回组件与样式；不改变上传、分页、拟合、实验记录或会话数据协议。图表保留坐标轴、单位、图例、分析范围及残差语义。只需前端设计，不新增数据库、登录、支付、云存储或自动保存。
