# 材料科研谱线拟合工具

在本机浏览器中完成一维谱线拟合：通用／Raman 和 XRD 均使用统一拟合工作区，导入后不自动创建或识别峰，由用户手动选峰；全部峰在同一弹窗中调整参数，并统一使用一种峰函数。添加或停用峰后按启用数量自动选择原单峰或联合求解器；另有独立的 XPS 工作台。多峰可先选择“图上添加峰”，再点击图表位置建立初值。批量流程按指定顺序继承上一条结果，重新优化当前谱，并记录重试、警告和来源。

**[中文使用手册](docs/USER_GUIDE.md)** · **[公开实谱与复现](examples/public/README.md)** · **[合成练习](examples/README.md)**

**[六步骤验收复测（2026-11-03）](examples/acceptance/peak_fitting/README.md)**：修复参数触及边界时的不确定度输出及提示后，本机样例包六步骤通过；附报告、原样例和完整证据包，判定范围及正式现场验收限制见报告。

本项目仅面向 **PC 浏览器**使用。紧凑顶栏管理分析类型与本地会话；单谱采用设置、图谱、结果三栏，设置及结果栏可拖动分隔线或通过“布局”调整宽度。可独立收起结果、一键放大图谱并按 Esc 返回；桌面窗口较窄时结果移到图谱下方。切换视图保留配置、图谱缩放及结果；批量页面保留历史尝试与配置。

![紧凑科研工作台：公开 XPS 实谱](docs/images/43-workbench-redesign.png)

图文手册包含实际操作截图与公开实谱拟合图，演示 Raman、XRD、XPS 的选列、区间、参数弹窗、配置恢复和残差诊断，并说明统一图表字号、点线残差及桌面布局。部分截图来自此前版本，当前入口以手册文字说明为准。数据来自 [Gnatyuk 等的 Zenodo 数据集](https://doi.org/10.5281/zenodo.18845748)；[完整署名和处理说明](examples/public/README.md)。

## 功能

| 模式 | 峰形 | 背景与分析 |
| --- | --- | --- |
| 通用拟合、XRD 拟合 | Gaussian、Lorentz、PsdVoigt1、PsdVoigt2、Split Pseudo-Voigt、双方向 EMG，全部峰统一选一种 | 共用区间、基线、图上选峰与参数弹窗；单峰保留初值估计、分阶段拟合和模型比较；多峰支持峰间约束 |
| XPS 多峰拟合 | 上述峰形中除 PsdVoigt2 外的六种，可混合 | 无背景、直线、静态 Shirley；候选峰、双峰组、峰位/面积/宽度关联、能量偏移 |

顶部按“分析类型”（通用谱线／XRD 峰拟合／XPS 峰拟合）和“处理方式”（单谱／批量）选择。批量入口：在单谱工作区拟合首谱，点击“用于批量拟合”，再导入多文件／多表／多 Y 列；也可直接进入批量页面加载同类型配置 JSON。批量策略可选独立拟合或顺序拟合。支持一峰模板、上一谱初值继承、有限续算、连续计算后集中复核、快照 CSV／JSON 导出。详见[多峰与批量操作](docs/USER_GUIDE.md#通用多峰与批量顺序拟合)。

计算、诊断和人工接受分别显示；批量默认连续完成全部计算；残差相关等异常结果保留待复核且不传递初值，下一谱从模板开始，人工接受仍保留警告。单谱与批量共用峰结果表，点击峰名直接查看参数并突出对应曲线，不再显示独立详情按钮。

批量先选择文件／工作表中的 X 与原谱 Y 列，再生成任务；支持自然排序预览、分页背景概览，以及按执行序号或实验条件查看峰位置、FWHM 和面积趋势。实验记录随批次追溯 JSON 版本 2 导出，可按原文件哈希和谱列载回。这一入口只载入实验记录；完整恢复使用独立的本地会话入口。

阶段 C 增加可选数据清理审计、实际采样支持诊断、独立方案敏感性比较、本地会话 JSON v1 与可打印 HTML 摘要。会话保存当前单谱或批次的原谱、配置、结果及历史，服务重启后可显式恢复；载入不自动拟合，继续前重新预览并复核背景。HTML 摘要引用已保存结果，不重新求解。详见[保存恢复与分析摘要](docs/USER_GUIDE.md#本地会话-json独立版本-1)。

峰面积 `A` 为模型全域积分面积，峰位 `xc` 为实际峰顶。请区分整体 FWHM、模型内部宽度和区间面积；数值收敛不等于模型适用或化学态归属正确。详细口径见手册。

顶部“输入方式 → 拟合结果解析”可直接读取外部 CSV／Excel 峰参数宽表或长表，明确列映射、单位与量义后，使用多步公式、晶面间距／立方晶格常数、Scherrer 相干域尺寸、相对晶面应变、各向同性 WH 微应变及标样线性含量模板。已有单谱／批量结果可通过“用拟合结果计算材料参数”进入同一工作区。支持映射模板复用、坏行隔离、结果 CSV／HTML 和独立解析档案 JSON；操作与条件见[拟合结果解析与材料参数计算](docs/USER_GUIDE.md#拟合结果解析与材料参数计算)。

## Windows 快速开始

1. 安装 Python 3.10～3.12（推荐 3.11/3.12）以及包含 npm 的 Node.js 18 或更高版本。当前 NumPy 1.x 依赖不适用于 Python 3.13/3.14。
2. 下载仓库 ZIP 并解压，或克隆仓库；进入含 `一键启动.bat` 的目录。
3. 双击 **`一键启动.bat`**。首次启动需要联网，脚本创建 `.venv` 并安装依赖。
4. 浏览器自动打开 <http://127.0.0.1:5175/>。导入 `examples/public/zenodo_18845748/Raman.xlsx`，选择 `Bare Ge / Wavenumber / Pristine #1`，按[图文教程](docs/USER_GUIDE.md#首次拟合教程)操作。
5. 结束时回到启动窗口按回车，停止本次启动的前后端。仅关闭网页不会停止服务。

```powershell
# 在项目根目录执行；不自动打开浏览器
.\一键启动.bat -NoBrowser

# 检查前后端 HTTP 服务，成功后自动停止
.\一键启动.bat -Check
```

手动安装、双终端启动和构建后单服务运行，见[安装与启动](docs/USER_GUIDE.md#安装与启动)。

## 数据与结果

- 导入 CSV、TXT、TSV、DAT、XY、XYE、XLS、XLSX、XLSM，单文件上限为 25 MiB；导入弹窗支持所有工作表、全部解析列与分页数据（每页 100 行、支持跳页），先核对建议 X/Y，明确应用后才替换分析；失败或取消保留旧数据。
- 本地服务在内存中处理导入数据，不覆盖原文件。参数弹窗支持撤销本次修改，替换／清空前提示影响，刷新／关闭有离开提醒；没有自动保存；请显式下载本地会话 JSON，并保留原始实验文件。会话上限为 100 MiB、100 谱、200,000 个原谱点，不包含未纳入草稿及临时方案编辑。
- 单峰、多峰和 XPS 均可导出曲线 CSV、参数 CSV、拟合图 PNG 与配置 JSON。XPS 页面直接导出当前拟合结果，不重复求解；统一工作区的单峰 JSON 保留分阶段求解设置。已有配置仍可复用。
- 批量导出按“当前谱线／整个批次”显示完成、待复核、失败等状态，可直接定位待复核或失败谱线。文件生成失败会显示原因，可重新点击导出；发起下载后请在浏览器下载列表中查看。
- 仓库附带经核验、按 CC BY 4.0 署名转载的公开 Raman/XRD/XPS 原谱，以及合成练习；个人实验数据、历史分析输出、缓存和日志不随仓库发布。

后端为 FastAPI、NumPy、SciPy、pandas；前端为 Vue 3、TypeScript、Vite、Plotly。


外部峰表解析与二次计算的合成算术样例可单独复算（只读样例，不覆盖原文件）：



## 当前边界

XRD 原谱工作区提供单峰／多峰局部拟合，保留观测峰宽，不自动作物相鉴定。独立材料参数模板在波长、峰宽定义、仪器标准样和模型假设明确时支持展宽校正与尺寸估计；Scherrer 输出为相干衍射域尺寸，不等同于显微组织晶粒尺寸。XPS 暂不包含 Tougaard、多重态专用模型、自动化学态归属、RSF 定量、测量误差加权或批量联合拟合。Gaussian、Lorentz 净峰高在协方差可用时报告传播标准误和 95% 置信区间。其他派生几何量及新增材料参数暂不计算标准误或置信区间；真实厂商格式仍需提供代表性文件后逐项确认。

峰结果解析单文件上限为 25 MiB，每批标准化／每次计算最多 10,000 个峰；计算请求还受累计文本 10 MiB、节点数量及公式运算量限制，较大的表或多步公式需分批处理。解析档案使用独立的 `peak-analysis` 版本 1，与原谱本地会话、批次追溯 JSON 分别保存和恢复。

本项目面向本机使用，未提供用户认证或面向公网的部署配置。

完整数据浏览使用只读接口 `GET /api/datasets/{id}/rows?sheet=…&offset=0&limit=100`，每页最多 500 行，沿用数据集一小时有效期；返回列名、解析行号、行数据与总行数，不修改拟合数据。更新此功能后，已启动的旧后端需重新启动以加载接口。
